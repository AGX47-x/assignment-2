; --- Vole Machine Test Program ---
; This program prints "HELLO 1234" to the screen (address 0xFF)

; 1. Load ASCII letters into registers and store to screen (0xFF)
2148 ; Load R1 with 'H' (Hex 48)
31FF ; Store R1 to screen (0xFF)
2245 ; Load R2 with 'E' (Hex 45)
32FF ; Store R2 to screen (0xFF)
234C ; Load R3 with 'L' (Hex 4C)
33FF ; Store R3 to screen (0xFF)
244C ; Load R4 with 'L' (Hex 4C)
34FF ; Store R4 to screen (0xFF)
254F ; Load R5 with 'O' (Hex 4F)
35FF ; Store R5 to screen (0xFF)
2620 ; Load R6 with Space (Hex 20)
36FF ; Store R6 to screen (0xFF)

; 2. Load numbers (using ASCII codes: '1' = 31, '2' = 32, etc.)
2731 ; Load R7 with '1' (Hex 31)
37FF ; Store R7 to screen (0xFF)
2832 ; Load R8 with '2' (Hex 32)
38FF ; Store R8 to screen (0xFF)
2933 ; Load R9 with '3' (Hex 33)
39FF ; Store R9 to screen (0xFF)
2A34 ; Load R10 with '4' (Hex 34)
3AFF ; Store R10 to screen (0xFF)

; 3. Halt the machine execution
C000 ; Halt
